# MAX Chat

Чат на React для отправки и получения текстовых сообщений в MAX через GREEN-API.

[Открыть приложение](https://totoshka19.github.io/green-api-max-chat/)

## Локальный запуск

Нужны Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Приложение откроется по адресу http://127.0.0.1:5173.

## Подключение

1. Создайте инстанс **MAX: Developer** в [GREEN-API](https://console.green-api.com/) и подключите свой MAX по QR-коду.
2. Дождитесь статуса «Авторизован».
3. В настройках уведомлений включите входящие сообщения, статусы отправленных сообщений и изменение состояния авторизации. URL webhook оставьте пустым, режим отладки выключите.
4. В приложении введите `idInstance` и `apiTokenInstance`. Если `apiUrl` отличается от значения по умолчанию, укажите его в дополнительных настройках.
5. Создайте чат по номеру телефона, отправьте сообщение и попросите собеседника ответить из MAX.

Бесплатный тариф допускает три чата. Поиск получателя через `CheckAccount` поддерживает номера РФ (+7) и Беларуси (+375). Для проверки переписки нужны два разных аккаунта MAX.

## Возможности

- Создание личных чатов по номеру телефона.
- Отправка текста до 4000 символов и получение ответов.
- Статусы отправки, доставки и прочтения.
- Поиск чатов, непрочитанные сообщения и отдельные черновики.
- Enter отправляет сообщение, Shift + Enter добавляет строку.
- Восстановление получения сообщений после сетевых ошибок.
- Адаптивный интерфейс по мотивам веб-версии MAX.

Ключ и переписка хранятся в памяти вкладки и очищаются при выходе или перезагрузке. Отправка автоматически не повторяется: при ошибке текст остаётся в поле ввода.

## Проверки и сборка

```bash
npm test
npm run lint
npm run build
npm run preview
```

Сборка находится в `dist/`. Публикация на GitHub Pages запускается при push в `main`; workflow сначала выполняет тесты, линтер и сборку.

## Устройство проекта

React, TypeScript, Vite и обычный CSS. Состояние переписок хранится в reducer, запросы к API выделены в отдельный модуль.

- `src/chat/api.ts` - HTTP-клиент GREEN-API.
- `src/chat/model.ts` - сообщения, статусы и дедупликация.
- `src/chat/polling.ts` - последовательное получение и подтверждение уведомлений.
- `src/chat/useChat.ts` - подключение и действия пользователя.
- `src/components/` - форма подключения и интерфейс чата.

Получение работает через `ReceiveNotification` и `DeleteNotification`. После обработки уведомление подтверждается; повторно доставленные сообщения отбрасываются по `chatId` и `idMessage`. При выходе запросы отменяются через `AbortController`.

Тесты находятся рядом с кодом. В интеграционных тестах подменяется только сеть, реальные ключи не используются.

## Ограничения

Приложение отображает только личные текстовые сообщения. Уведомления о других типах сообщений подтверждаются и пропускаются. История между сессиями не сохраняется; приложение должно быть единственным потребителем HTTP-уведомлений своего инстанса.

Ключ используется в запросах браузера к GREEN-API и не включён в исходники или сборку. Каждый пользователь вводит собственные данные подключения.
